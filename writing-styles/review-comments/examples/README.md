# Review Comment Examples

One review of one pull request at the PB&J Machine Company: #212, which adds a Remove sandwich button to the order review screen. Sam is the user, the person the reviewer works for.

| File | What It Shows |
|---|---|
| [`body.md`](body.md) | The review's body: what the pull request does in product language, then restated as the reviewer understood it, and any overall Questions |
| [`call-product.md`](call-product.md) | A product decision, left to the author with the reviewer's recommendation |
| [`call-code.md`](call-code.md) | A code decision, left to the author with the reviewer's recommendation |
| [`fix-changes-behavior.md`](fix-changes-behavior.md) | A Fix the person using the product would notice, with its journey; then two from other pull requests, a defect in a library's default, and one on a single platform |
| [`fix-no-behavior-change.md`](fix-no-behavior-change.md) | A Fix nobody would notice, with no journey |
| [`fix-document.md`](fix-document.md) | A Fix to a document the pull request left wrong |
| [`nit.md`](nit.md) | A preference |
| [`question.md`](question.md) | Something the reviewer couldn't find out itself |
