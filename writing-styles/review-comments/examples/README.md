# Review Comment Examples

One review of one pull request at the PB&J Machine Company: #212, which adds a Remove sandwich button to the order review screen. Sam is the user, the person the reviewer works for.

| File | What It Shows |
|---|---|
| [`body.md`](body.md) | The review's body: the pull request restated as the reviewer understood it, and any overall Questions |
| [`call-product.md`](call-product.md) | A product decision, with the user's recommendation |
| [`call-code.md`](call-code.md) | A code decision, with the reviewer's recommendation |
| [`call-left-to-the-author.md`](call-left-to-the-author.md) | A decision left open, with no recommendation |
| [`fix-changes-behavior.md`](fix-changes-behavior.md) | A Fix the person using the product would notice, with its journey |
| [`fix-no-behavior-change.md`](fix-no-behavior-change.md) | A Fix nobody would notice, with no journey |
| [`fix-document.md`](fix-document.md) | A Fix to a document the pull request left wrong |
| [`nit.md`](nit.md) | A preference |
| [`question.md`](question.md) | Something the reviewer couldn't find out itself |
