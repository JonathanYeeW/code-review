# Procedures

What an LLM follows, step by step. Each one has a CPF in `../docs/` that tells the same story.

| File | Trigger | What It Produces |
|---|---|---|
| `sop_set-up.md` | `set up the reviewer`, or `teach the reviewer` | An install, and standards from a first stack |
| `sop_review-a-pr.md` | `review this PR <link>` | A posted review, seen through to the final approval |
| `sop_harvest.md` | The user's go or no-go on a pull request, or `harvest <pull request>` | Updated memory, and a short note |
